# Fallback prompts

## Grill me
Before writing any code, ask me questions one at a time about requirements,
edge cases and trade-offs until the plan is solid. Wait for my answer before
asking the next question. When we're done, summarise the decisions in a short
PLAN.md: goal, input/output, out of scope, steps, and how we'll test it.

## Working preferences
For this session: explore the relevant code before proposing changes, propose
a short plan and wait for my approval, then work in small testable steps and
stop after each one so I can review. Follow existing patterns, keep it simple,
don't add dependencies without asking, and run the tests after every change.
